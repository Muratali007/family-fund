# Отбасы Қоры — семейный сбор денег

Члены семьи регистрируются (указывают, кто они: отец, келін, братишка и т.д. и кому приходятся), загружают аватар,
предлагают вещи (фото, цена, сколько своих денег есть). Остальные голосуют. Если **все** одобрили — начинается сбор:
видно, сколько собрано, сколько осталось и кто сколько внёс. Если кто-то против — заявка отклоняется.

## Запуск локально

```bash
npm install
npm start          # http://localhost:3000
```

Локально используется встроенный SQLite (`data/app.db`), ничего ставить не нужно (Node 22.13+).

## Бесплатный деплой: Render + Neon

Render (бесплатный хостинг) стирает файлы при перезапуске, поэтому данные храним в бесплатном Postgres от Neon.
Фото и аватарки сохраняются прямо в базе (сжатые на телефоне), отдельное хранилище файлов не нужно.

1. **База:** зарегистрируйтесь на https://neon.tech → New Project → скопируйте *Connection string*
   (вида `postgresql://user:pass@ep-xxx.neon.tech/neondb?sslmode=require`).
2. **GitHub:** создайте пустой репозиторий и отправьте код:
   ```bash
   git remote add origin https://github.com/<ваш-логин>/family-fund.git
   git push -u origin main
   ```
3. **Render:** https://render.com → войти через GitHub → **New → Blueprint** → выберите репозиторий.
   Render прочитает `render.yaml`, спросит `DATABASE_URL` — вставьте строку из Neon. `JWT_SECRET` создастся сам.
4. Через 2–3 минуты сайт будет доступен по адресу `https://family-fund-xxxx.onrender.com`.

> На бесплатном тарифе Render сайт «засыпает» после 15 минут без посетителей — первое открытие после паузы занимает ~30–50 секунд.

## Переменные окружения

| Переменная     | Назначение                                     |
|----------------|------------------------------------------------|
| `DATABASE_URL` | строка подключения Postgres (если нет — SQLite) |
| `JWT_SECRET`   | секрет для сессий (обязателен в продакшене)     |
| `NODE_ENV`     | `production` на сервере                        |
| `PORT`         | порт (Render задаёт сам)                       |
