# Отбасы Қоры — семейный сбор денег

Члены семьи регистрируются (указывают, кто они: отец, келін, братишка и т.д. и кому приходятся), загружают аватар,
предлагают вещи (фото, цена, сколько своих денег есть). Остальные голосуют. Если **все** одобрили — начинается сбор:
видно, сколько собрано, сколько осталось и кто сколько внёс. Если кто-то против — заявка отклоняется.

## Запуск локально

```bash
npm install
npm start          # http://localhost:3000
```

Локально используется встроенный SQLite (`data/app.db`), ничего ставить не нужно (Node 22.13+).

## Бесплатный деплой: Render + Neon

Render (бесплатный хостинг) стирает файлы при перезапуске, поэтому данные храним в бесплатном Postgres от Neon.
Фото и аватарки сохраняются прямо в базе (сжатые на телефоне), отдельное хранилище файлов не нужно.

1. **База:** зарегистрируйтесь на https://neon.tech → New Project → скопируйте *Connection string*
   (вида `postgresql://user:pass@ep-xxx.neon.tech/neondb?sslmode=require`).
2. **GitHub:** создайте пустой репозиторий и отправьте код:
   ```bash
   git remote add origin https://github.com/<ваш-логин>/family-fund.git
   git push -u origin main
   ```
3. **Render:** https://render.com → войти через GitHub → **New → Blueprint** → выберите репозиторий.
   Render прочитает `render.yaml`, спросит `DATABASE_URL` — вставьте строку из Neon. `JWT_SECRET` создастся сам.
4. Через 2–3 минуты сайт будет доступен по адресу `https://family-fund-xxxx.onrender.com`.

> На бесплатном тарифе Render сайт «засыпает» после 15 минут без посетителей — первое открытие после паузы занимает ~30–50 секунд.

## Kaspi и чеки

Автор вещи указывает номер Kaspi. Тот, кто помогает, переводит деньги в приложении Kaspi и прикрепляет чек (фото или PDF).
Взнос получает статус «⏳ проверяется» и не попадает в «Собрано», пока автор не нажмёт «✅ Деньги пришли».
Если перевода нет, автор нажимает «❌ Не пришли» и пишет причину. Сумма снова становится доступной, и человек может отправить чек ещё раз.

## Уведомления

- **WhatsApp:** на странице вещи есть кнопка «📲 В WhatsApp». Она открывает WhatsApp с готовым текстом, остаётся выбрать семейную группу.
- **Email (Brevo):** письма о новой вещи, голосах, начале сбора, переводах, их проверке и окончании сбора.
  1. Зарегистрируйтесь на https://brevo.com (бесплатно 300 писем в день).
  2. **Senders, Domains & Dedicated IPs → Senders → Add a sender:** добавьте свой email и подтвердите его.
  3. **SMTP & API → API Keys → Generate a new API key.**
  4. На Render в разделе **Environment** задайте `BREVO_API_KEY` (ключ) и `MAIL_FROM` (подтверждённый email).
  Без этих переменных сайт работает, просто не отправляет письма.

## Возможности

- **Регистрация и вход**, восстановление пароля по email (ссылка действует 1 час), смена пароля, «выйти на всех устройствах».
- **Защита от подбора пароля:** не больше 10 попыток входа за 15 минут на один email.
- **Глава семьи** (создатель): исключить участника, сменить код приглашения, переименовать семью, передать главенство.
- **Вещи:** голосование → сбор (Kaspi + чек, подтверждение получателем) → «Собрано» → «Куплено» (фото покупки или чек магазина).
- **Редактирование заявки.** Пока идёт голосование, можно менять всё; если поменять цену или название, голоса сбросятся. После одобрения можно менять только описание, фото, Kaspi и срок. Отклонённую заявку можно предложить ещё раз.
- **Срок сбора** с обратным отсчётом.
- **Напоминания** (push и email, раз в час):
  - голос не отдан сутки;
  - чек не проверен 2 суток;
  - до срока осталось 3 дня и меньше.

  Не чаще раза в сутки и не больше 3 раз.
- **Обсуждение** у каждой вещи, с ответом на конкретный перевод.
- **Статистика:** кто сколько помог, сборы по месяцам, история покупок.
- **Два языка:** русский и казахский. Уведомления приходят на языке получателя.
- **PWA:** установка на телефон, push-уведомления.

## Чтобы сайт не засыпал

Workflow `.github/workflows/keepalive.yml` раз в 10 минут обращается к `/healthz`. Он бесплатный для публичных репозиториев.
GitHub отключает расписание, если в репозитории 60 дней не было коммитов. Включить его снова можно во вкладке **Actions**.
Ещё надёжнее — бесплатный монитор на uptimerobot.com с интервалом 5 минут на тот же адрес.

## Переменные окружения

| Переменная     | Назначение                                     |
|----------------|------------------------------------------------|
| `DATABASE_URL` | строка подключения Postgres (если нет — SQLite) |
| `JWT_SECRET`   | секрет для сессий (обязателен в продакшене)     |
| `NODE_ENV`     | `production` на сервере                        |
| `PORT`         | порт (Render задаёт сам)                       |
| `BREVO_API_KEY`| ключ Brevo для писем (необязательно)           |
| `MAIL_FROM`    | email отправителя, подтверждённый в Brevo      |
| `MAIL_FROM_NAME`| имя отправителя (по умолчанию «Отбасы Қоры») |
| `APP_URL`      | адрес сайта для ссылок в письмах (по умолчанию берётся из запроса) |
